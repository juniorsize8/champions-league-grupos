# Champions League — Fase de Grupos

Site para lançamento de resultados e classificação ao vivo da fase de grupos (16 grupos, 4 jogadores cada, todos jogam entre si).

## Rodar localmente
```
npm install
npm start
```
Acesse http://localhost:3000

## Publicar no Render
1. Suba esta pasta para um repositório no GitHub.
2. No Render: New + → Web Service → conecte o repositório.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Plano Free é suficiente.

## Pontuação
- Vitória normal: 3 pts
- Vitória no tie-break (placar 7x6): 2 pts
- Derrota no tie-break: 1 pt
- Derrota normal: 0 pts
